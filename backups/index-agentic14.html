📁 Agentic Folder Automation (Local, Zero API-Token Loop)
"Select / Create Agent Folder" needs one click (browser security requirement for showDirectoryPicker). After that, everything below — reading files, running inference, writing outputs, renaming processed files — runs with no further clicks, driven by an interval loop. Reloading the page will require one more click to re-confirm folder permission; that's a browser-enforced limit, not something JavaScript can route around.

When checked, the model's response is scanned for markers like this and each block is written to its own file (subfolders like css/style.css are created automatically): 
=== FILE: index.html ===
<!DOCTYPE html>...

=== FILE: css/style.css ===
body { ... }

=== FILE: script.js ===
console.log("hi");
Your base prompt below needs to actually instruct the model to respond in this format — the toggle only controls how the response gets parsed, it doesn't change what the model writes. If no markers are found in a response, it falls back to writing the whole thing as one file. The three names above (index.html, css/style.css, script.js) are just an example of the marker syntax — the parser itself doesn't care what the names are or how many files there are. If you want the model to invent its own filenames and file count, say so explicitly in the base prompt; it won't do that on its own just because the toggle is checked. Click "Load creative example" below for a starter prompt written that way.
Max auto-chain iterations (same file):
File variables: write ${input}, ${filename}, or ${iteration} anywhere in the prompt above to reference the file currently being processed. Any other ${name} is looked up against the other files sitting in the folder right now, matched by the variable name shown in the File Browser panel below — e.g. ${sensor1} pulls in the live content of sensor1.in.txt.
All of this — input mode, input/output filenames, poll interval, max iterations, auto-chain — is saved to and reloaded from config.json, so "Save config.json" / "Relink Last Folder" round-trip the whole setup, not just the base prompt.
